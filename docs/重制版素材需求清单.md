# 《MARS》重制版素材需求清单

> 本清单用于收集美术、音频与剧情资料。所有项目都允许暂时空缺，开发初版时使用色块、文字标签和临时素材占位。

## 交付总规则

- 原始素材放入单独文件夹，不覆盖旧版文件。
- 文件名使用英文小写和下划线，例如 `hina_work_neutral.png`。
- 图片优先交付无损 PNG；需要透明背景的素材必须保留 Alpha 通道。
- 音乐优先交付 WAV 或高质量 OGG；不要只保留低码率 MP3。
- 同一角色的立绘尽量固定 NAI 模型、提示词、采样参数、画幅和种子，并保存生成信息。
- 找到的第三方素材附带来源链接和许可证文本；即使只做个人游戏，也方便以后替换和追溯。
- 不需要自行裁切、重命名或导入 Godot；提供原文件即可，由项目统一处理。

## P0：制作初版前最有价值的内容

这些内容会明显提高初版质量，但没有也可以开工。

### 1. 希娜基准设计图

- [ ] 工作服正面基准立绘 1 张
- [ ] 火星外勤服正面基准立绘 1 张
- [ ] 角色全身比例参考 1 张
- [ ] Hello Kitty 幸运物的具体外观与位置参考
- [ ] 锁骨旧伤的形状与位置参考

推荐规格：

- 透明 PNG
- 竖图，建议至少 1600×2400
- 人物从头到脚完整，不裁手、不裁发梢
- 光源尽量中性，避免复杂背景光污染人物颜色
- 工作服主色、外勤服主色和瞳色保持一致

NAI 生成时建议保留：模型名称、Prompt、Negative Prompt、Seed、Sampler、Steps、CFG/Prompt Guidance。

### 2. 视觉方向参考

- [ ] 火星地表气氛参考 3–5 张
- [ ] 基地内部参考 3–5 张
- [ ] 地下洞穴或遗迹参考 3–5 张
- [ ] 喜欢的游戏 UI 或对话框参考 2–4 张
- [ ] 像素画风格参考 2–4 张

这些图片只用于确定方向，可以是电影截图、游戏截图或概念图，不会直接打包进游戏。

### 3. 设定中仍未确定的文字信息

- [ ] 主角国籍与出生地
- [ ] 主角默认姓名（玩家仍可修改）
- [ ] Hello Kitty 幸运物是谁送给希娜的
- [ ] 希娜锁骨旧伤的来源
- [ ] 基地 AI 的名称、语气和人格程度
- [ ] F-47 任务原本的公开目标
- [ ] 火星基地名称
- [ ] 故事大致年代是否继续使用公元 6202 年

## P1：第一章可玩版本素材

### 1. 希娜对话立绘

第一批只做细微、自然的表情，不做夸张颜艺。

- [ ] `hina_work_neutral`：工作服、冷静/中性
- [ ] `hina_work_focused`：专注、分析数据
- [ ] `hina_work_worried`：克制的担心
- [ ] `hina_work_annoyed`：真正不满，不是无故傲娇
- [ ] `hina_work_tired`：疲惫、虚弱
- [ ] `hina_work_soft_smile`：很轻的微笑
- [ ] `hina_suit_neutral`：完整外勤服
- [ ] `hina_injured`：迫降后受伤版本，血腥程度克制
- [ ] `hina_medical_sleep`：医疗舱昏迷状态

制作方式建议：

- 先确定一张基准立绘，再通过重绘或局部修改制作表情。
- 所有表情保持脸型、发型、衣服、身体角度和画布位置一致。
- 立绘在游戏内主要显示为膝盖以上，仍建议保留全身原图。

### 2. 像素角色

推荐技术规格：32×48 像素角色画布，4 方向，每方向 3–4 帧行走动画。

- [ ] 主角：待机、上下左右行走
- [ ] 希娜工作服：待机、上下左右行走
- [ ] 希娜外勤服：待机、上下左右行走
- [ ] 希娜受伤状态：静态或简化动画

NAI 不适合直接生成严格对齐的像素动画，可以先找 CC0 占位角色，最后再人工统一绘制。

### 3. 第一批地图素材

统一使用 32×32 像素瓦片。

基地内部：

- [ ] 金属地板、墙体、墙角和门
- [ ] 气闸门与密封门
- [ ] 医疗舱/病床
- [ ] 生命保障控制台
- [ ] 储物柜、工具柜、桌椅
- [ ] 电缆、管道、通风口
- [ ] 警示灯、普通照明和损坏状态
- [ ] 温室培养床和植物生长阶段

火星地表：

- [ ] 红色沙地基础瓦片及变化
- [ ] 岩石、坑洞、裂缝、坡地
- [ ] 飞船残骸与散落物资
- [ ] 基地外墙、太阳能板、天线
- [ ] 采集点、任务标记和不可通行边界
- [ ] 沙尘、风痕和低能见度覆盖层

### 4. 第一章场景插画/CG

均可后补，初版使用纯色背景与文字描述。

- [ ] F-47 起飞
- [ ] 火星迫降
- [ ] 主角将希娜送入医疗舱
- [ ] 第一次从基地看见火星日出

推荐规格：3840×2160 或至少 2560×1440，无文字版本。

### 5. 第一批音乐

- [ ] 标题界面：孤独、辽阔、带希望
- [ ] 飞船/序章：安静的科技感
- [ ] 迫降危机：紧张但不偏动作大片
- [ ] 基地日常：克制、温暖、可长时间循环
- [ ] 火星地表：空旷、低频、风感
- [ ] 希娜主题：冷静外表下有柔软感

Suno 建议：

- 纯音乐，不带人声和歌词。
- 每首保留无缝循环版和正常结束版。
- 避免旋律过满，确保长时间循环不疲劳。
- 保留生成提示词和版本信息。

### 6. 第一批音效

- [ ] 菜单移动、确认、取消
- [ ] 金属地板脚步
- [ ] 火星地表脚步
- [ ] 气闸开关与加压/泄压
- [ ] 普通门与损坏门
- [ ] 控制台按键和扫描
- [ ] 设备低频运转声
- [ ] 警报声
- [ ] 舱外风声与沙尘暴
- [ ] 工具维修声
- [ ] 氧气呼吸声
- [ ] 水循环声
- [ ] 医疗设备提示声
- [ ] 火星车启动与行驶

音效优先 WAV，单声道或立体声均可；不要提前叠加游戏内混响。

## P3：完整版本与最终润色

### 1. 剧情文本

- [ ] 六章章节大纲
- [ ] 每章必须发生的事件清单
- [ ] 主角与希娜的关系阶段表
- [ ] 关键选择及其短期后果
- [ ] 所有主线对白
- [ ] 基地日常事件
- [ ] 探索事件和环境叙事文本
- [ ] 终章与唯一正式结局
- [ ] 通关后的事件图鉴说明

建议先写事件梗概，再写对白；不要从第一句开始一路写到结局。

### 2. 完整 UI 素材

- [ ] 游戏 Logo 与标题字样
- [ ] 主菜单背景
- [ ] 面板、按钮、滚动条和焦点框
- [ ] 氧气、伤势、辐射、时段图标
- [ ] 电力、水、食物、氧气、医疗物资图标
- [ ] 物品、工具、样本和制作配方图标
- [ ] 地图标记和任务状态图标
- [ ] 存档槽缩略图边框
- [ ] 鼠标光标

建议所有功能图标使用同一套线宽和视角；危险状态不能只依靠红/绿色区别。

### 3. 完整音乐方向

- [ ] 标题
- [ ] 序章航行
- [ ] 迫降危机
- [ ] 基地白天
- [ ] 基地夜晚
- [ ] 温室/温暖日常
- [ ] 火星地表
- [ ] 沙尘暴
- [ ] 地下洞穴
- [ ] 遗迹
- [ ] 未知生命/追逐
- [ ] 争执或关系低谷
- [ ] 浪漫场景
- [ ] 终章
- [ ] 片尾

不要求 15 首完全独立曲目，可以通过主题变奏减少风格割裂。

### 4. 字体

- [ ] 正文中文字体：清晰、长期阅读不疲劳
- [ ] 科技数据显示字体：数字宽度稳定
- [ ] 标题字体：具有科幻气质但不影响辨认

字体必须允许嵌入游戏。优先寻找 SIL Open Font License 或明确允许游戏嵌入的字体。

### 5. 发布前素材检查

- [ ] 所有占位图已经替换或明确保留
- [ ] 所有角色立绘的比例、光源和服装细节统一
- [ ] 所有像素素材遵循相同分辨率和像素密度
- [ ] BGM 音量已经统一
- [ ] 音效没有明显底噪或削波
- [ ] 第三方素材保留来源和许可证记录
- [ ] 游戏内制作人员与素材鸣谢完整

## 推荐的提交文件夹结构

你可以按下面方式随手投放素材；不完整也没关系。

```text
待整理素材/
├─ character/
│  ├─ hina/
│  ├─ protagonist/
│  └─ supporting/
├─ pixel/
│  ├─ characters/
│  ├─ base/
│  ├─ mars/
│  └─ ruins/
├─ cg/
├─ ui/
├─ audio/
│  ├─ bgm/
│  └─ sfx/
├─ references/
└─ writing/
```

每批素材旁可以附一个 `说明.txt`，写明用途、版本以及你是否满意。未写说明的素材默认视为候选稿，不直接替换正式内容。
