A. 米多莉·希娜
基础设定
姓名：米多莉·希娜（Midori Hina）
年龄：23岁左右
国籍：日本
职业：行星地质调查员 / 火星地质学家
出生在日本，但少年时期因为父母的工作，在月球或近地轨道科研基地生活过几年。
这样有几个好处：
- 她并不是第一次离开地球，所以不会表现得像普通游客。
- 她熟悉低重力、舱内生活和科研任务。
- 她可以很自然地成为火星任务成员。
- 又不会让她什么都会——她擅长地质，不应该顺便会修飞船、开所有载具、懂医学。
她选择行星地质，很大程度上是因为小时候长期生活在封闭空间，对“真正未知的土地”有一种执念。
她不是那种高喊“为了人类探索宇宙”的理想主义科学家。
更像：
“我只是想知道那里到底有什么。”

性格关键词：
冷淡 / 嘴硬 / 理性 / 好胜 / 防备心强 / 实际上很细心 / 不擅长表达依赖
她不是典型傲娇。
最大的区别是：
她不会无缘无故骂主角，也不会动不动脸红。
比如主角出去维修设备，她真正担心的时候不会说：
“我担心你。”

而是：
“氧气剩余量检查了吗？”
“备用电池呢？”
“……你最好别让我一个人处理两个人的工作。”

等主角回来以后，她可能只是说一句：
“回来就好。”

这种会比传统傲娇自然很多。
专业与能力
希娜最强的部分应该非常明确：
- 行星地质
- 矿物识别
- 地层分析
- 地下结构判断
- 火星样本采集
- 探测设备使用
- 基础野外生存
- 科研数据分析
中后期发现地下遗迹 / 地下洞穴 / 火星生命迹象以后，她就是核心角色。
但她有几个明显短板：
- 不擅长复杂机械维修
- 飞行水平很一般
- 生命保障系统只懂基本操作
- 医疗只有航天员标准急救水平
- 力量不算大
这样就自然形成：
主角负责“让两个人活下来”，希娜负责“弄清楚火星到底发生了什么”。
害怕的东西
我反而不建议给她什么“怕蜘蛛”“怕黑”的萌属性。
她真正害怕的可以是：
失去控制。
所以她特别讨厌：
- 不知道发生了什么
- 无法掌握的数据
- 被别人替自己做决定
- 身体失去行动能力
这和游戏开局非常契合。
因为旧版最经典的设定之一就是：
她受伤昏迷，主角独自照顾她。
希娜醒来以后发现自己竟然完全依赖一个刚认识不久的人活了下来，对她来说其实是一件非常难接受的事情。
这也可以解释她为什么前期对主角态度有点刺。
讨厌
她可以明显讨厌：
- 毫无计划地冒险
- 不珍惜设备
- 浪费食物
- 别人把她当成需要保护的弱者
- 主角受伤还说“没事”
- 被人看穿自己的情绪
最后这个尤其适合恋爱剧情。
珍惜的东西
这里一定要把旧版那个很有辨识度的东西留下：
Hello Kitty 幸运物
过去设定里她有一个 Hello Kitty 头盔相关的幸运物，我觉得特别应该保留。
因为它和她平时的形象反差太大。
平时：
冷淡、专业、说话直接的火星地质学家。

结果主角某一天发现：
她用了很多年的私人装备上居然贴着一个已经有些褪色的 Hello Kitty。

主角：
“你喜欢这个？”

希娜：
“以前别人送的。”

主角：
“谁？”

希娜：
“……你问题很多。”

甚至可以一直到中后期才告诉主角来源。
它可以是母亲、姐姐或者童年朋友送给她的。
我甚至建议把它升级成希娜最重要的个人物品之一。
希娜必须保留的外形
旧版已经有几样很好：
娇小身材 + 棕色头发 + 冷淡的棕色眼睛 + 锁骨旧伤疤。
建议新版固定：
- 身高约 155–160cm
- 深棕色中短发
- 棕色眼睛
- 身材偏瘦
- 锁骨附近有一道不太明显的旧伤
- 日常很少化妆
- 工作服经常卷袖子
- 火星外勤服有一个很不起眼的 Hello Kitty 标记
不用把她做成“动漫式超级美少女”。
应该是第一眼：
有点冷，不太容易接近。
熟悉以后才会越来越觉得她可爱。
与主角关系变化

另外建议删除或弱化：
- 希娜过度毒舌
- 为了“傲娇”而傲娇
- 随机聊天增加好感这种纯数值设计
- 一次维修就固定“希娜生命值 +3”这种游戏味很重的机制
- 过度强调生命值百分比
新版最好把希娜当人物，而不是需要把进度条从 50% 刷到 100% 的任务目标。

B. 主角
这一版我反而建议把主角背景认真固定下来。
名字可以让玩家自己输入，但他不是白纸人。
基础设定
年龄：25岁左右
国籍：未定
出生地：未定
这样玩家可以代入，又不会完全变成玩家本人。
职业：
航天飞行工程师 / 生命保障系统工程师
主角最初不是科研人员。
他的任务就是：
把科学家送到目的地，并确保基地不会把里面的人弄死。

所以他自然会：
- 驾驶飞船
- 驾驶火星车
- 处理导航
- 修电路
- 修氧气循环
- 修水循环
- 维护供电系统
- 做舱外作业
- 应急抢修
但他不懂火星地质。
看到石头就是：
“石头。”

希娜：
“这是层状硫酸盐沉积。”

主角：
“所以还是石头。”

这种互动以后应该很多。
为什么参加火星任务
我不建议写成：
“从小就梦想征服火星。”

太套路。
可以是：
主角本来就是长期执行深空运输任务的工程师。
F-47 火星任务需要一名：
飞行 + 工程维修 + 生命保障复合型成员。
他是最合适的人之一。
而他报名还有一个私人原因：
他并不讨厌地球，但已经不知道地球哪里算自己的家。
长期深空工作以后，朋友逐渐疏远，家庭成员各自生活。
每次任务结束回到地球，他都会发现：
自己只是“回来”，却不是“回家”。

所以别人问：
“你为什么愿意去那么远？”

他会回答：
“反正都差不多。”

这句话前期听起来很洒脱。
但后来会形成一个非常漂亮的主题。
因为故事最后：
希娜变成了“想一起回去的人”。
甚至最后可以有一句：
希娜：“你以前不是说，去哪都一样吗？”  
主角：“现在不一样了。”

我觉得这会非常适合作为整部故事的情感核心。
主角性格
我建议：
温和理性为主 + 偶尔嘴贫 + 遇到危险时异常冷静。
不是高冷男主。
也不是热血笨蛋。
平常可能会跟希娜互怼。
但是出事故的时候会瞬间变成：
“希娜，听我说。氧气还有17分钟。现在沿着标记往东走，不要回头。”

这种反差会让他非常可靠。
他的一个明显缺点可以是：
习惯把自己的危险排除在计算之外。
他很擅长保护希娜。
却经常：
“我去就行。”

这会成为希娜最讨厌他的地方之一。
甚至后期两人大吵一架：
希娜真正生气的不是他冒险。
而是：
“为什么你的计划里永远没有你自己？”

这句话我很想保留。
两人初见
不要青梅竹马。
不要一上来互有好感。
就是纯粹的：
任务搭档。
出发前两个人只进行过短时间联合训练。
希娜觉得：
这人挺可靠，但话有点多。

主角觉得：
这个地质调查员是不是对我有意见？

实际上没有。
于是两人坐 F-47 前往火星。
原版的 6202年、拜科努尔、F-47 都可以暂时保留，因为这些已经是《MARS》的辨识度之一。

C. 新版《MARS》想要的故事元素
我先帮你做一版“故事愿望清单”，后面写剧情时就拿它当原则。
一定保留
- 米多莉·希娜
- 希娜嘴硬但实际上非常关心主角
- 希娜娇小
- Hello Kitty 幸运物
- 主角可以自定义名字
- 火星基地
- 两个人共同生活
- 生存资源管理
- 种植
- 基地维修
- 火星车
- 舱外活动
- 主角救下重伤昏迷的希娜
- 希娜醒来以后才真正开始两人的关系发展
- 慢热感情
- 地下洞穴 / 地下遗迹
- 火星生命
- 故事整体最终应该有希望
不想出现
- 恋爱三角
- 大量枪战
- 怪物潮
- 把游戏变成射击游戏
- 反派组织满火星追杀主角
- 复杂阵营斗争
- 大段政治说教
- 希娜为了傲娇无缘无故攻击主角
- 主角无脑热血
- 纯粹靠误会拖剧情
- 为虐而虐
- 突然杀死主角或希娜制造“神作感”
- 30天失败直接自杀
- 纯刷好感数值
特别想看到
- 科技感的剧情
- 富含情感变化的恋爱剧情
- 成功运作的游戏机制
