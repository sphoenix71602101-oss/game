# 占位素材说明

当前版本仅复用了用户旧版中的音乐，用于本地重制开发：

- `assets/audio/title_placeholder.mp3`
- `assets/audio/base_placeholder.mp3`
- `assets/audio/danger_placeholder.mp3`

这些文件应在正式发布前由用户提供的 Suno 音乐或许可证明确的素材替换。

当前界面、火星地表、F-47 舱体、设备、互动标记和宇航员由 Godot 原生绘制，不引用外部图片资源。对话立绘区使用遥测轮廓占位，以后可在不改动对话布局的情况下替换正式立绘。

字体目前调用 Windows 系统中的 Bahnschrift 和微软雅黑 UI，符合当前 Windows-only 目标。如果未来发布到其他平台，需替换为允许嵌入的字体文件。
