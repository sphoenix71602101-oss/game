# 《MARS》重制项目——交接说明

## 当前状态

本项目将旧版 Python/CMD 游戏《MARS》重制为 Godot 4.7.2 Windows 单机游戏。

首轮“火星硬科幻界面＋内容重制”已实装。当前可玩流程从 F-47 下降开始，结束于气闸解锁和首次 EVA 准备完成。下一阶段应先收集对 UI、人物口吻、任务节奏和舱内动线的试玩反馈，再制作火星地表地图。

## 重要创作决定

- 类型：2D 俯视生存探索＋Galgame 对话＋基地经营。
- 气质：科学求生、慢热恋爱、异星生态悬疑。
- 平台：Windows，键盘鼠标。
- 主角：固定职业和性格，姓名可自定义。
- 女主：米多莉·希娜，唯一恋爱对象。
- 结构：章节式主线，唯一正式结局，不要求多周目理解核心剧情。
- 威胁：环境、孢子、遗迹活动结构；不做传统枪战和怪物潮。
- 立绘：用户未来使用 NAI 制作；当前使用遥测轮廓占位。
- 音乐：用户未来使用 Suno 制作；当前复用旧版音乐作占位。
- 缺少的正式素材均允许占位，不得阻塞系统开发。

## 当前 Godot 内容

- F-47 任务档案主菜单与乘员登记。
- 约 70 个叙事单元的 JSON 下降/迫降序幕。
- 程序化绘制的 F-47 迫降舱体、火星环境、设备与宇航员。
- 医疗舱 → 生命保障 → 黑匣 → 货舱 → 气闸的任务链。
- 逐字对话、长文本分页、表达选项和状态标记。
- 火星日、时段、任务与氧气/电力/水 HUD。
- 暂停、v2 存档和继续任务。
- 自动冒烟测试。

## 已知限制

- 场景和主角仍是程序化占位美术，尚无正式瓦片、立绘和像素动画。
- 字体依赖 Windows 系统中的 Bahnschrift 和微软雅黑 UI；跨平台发布前需嵌入可授权字体。
- 舱外探索、火星车、种植、制作和后续章节尚未实现。
